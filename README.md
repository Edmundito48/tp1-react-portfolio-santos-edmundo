## Descripción del Proyecto
Este proyecto es mi entrega para el Trabajo Práctico Nº 1 de Programación. Desarrollé un portfolio web personal en React usando Vite como entorno de trabajo. El objetivo principal fue poner en práctica los primeros temas vistos en la materia: cómo dividir la interfaz en componentes propios y reutilizables, cómo pasar información entre ellos usando props, recorrer listas con `.map()` y usar el hook `useState` para interactuar con la página (como mostrar más texto o filtrar los proyectos según la categoría).

## Tecnologías Utilizadas
- React
- Vite
- JavaScript
- CSS

## Requisitos Implementados
- Proyecto armado con Vite.
- Componentes modulares propios (`Header`, `Hero`, `About`, `Skills`, `Projects`, `Footer`).
- Envío de datos mediante props.
- Renderizado de listas dinámicas con `.map()` y uso de `key`.
- Manejo de estados con `useState` para interactuar con la interfaz.
- Eventos de clic (`onClick`).
