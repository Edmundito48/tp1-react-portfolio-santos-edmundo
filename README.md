## Descripción del Proyecto
Este proyecto corresponde al Trabajo Práctico Nº 2. Consiste en la transformación del portfolio de una sola vista (TP1) a una aplicación multipágina (SPA) utilizando React Router DOM. La interfaz mantiene un menú lateral estático (30%) que permite navegar por las diferentes secciones del contenido principal (70%) sin recargar la página.

## Tecnologías Utilizadas
- React + Vite
- React Router DOM
- JavaScript (ES6+)
- CSS Clásico (Diseño Responsive)
